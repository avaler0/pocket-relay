Pocket Relay for macOS
======================

Installation
------------

1. Drag "Pocket Relay.app" and "Start Pocket Relay.command" onto the
   Applications shortcut.
2. Open Applications in Finder.
3. Double-click "Start Pocket Relay.command".
4. Enter a display name and either paste a 64-character room topic or leave
   the topic blank to create a new room.

If macOS blocks the first launch because this development build is not
notarized, Control-click "Start Pocket Relay.command", choose Open, and
confirm. Grant Pocket Relay Bluetooth access when prompted, or enable it in:

  System Settings > Privacy & Security > Bluetooth

The room topic is an invite and discovery token, not a password. Anyone who
learns it can discover and participate in that room.
